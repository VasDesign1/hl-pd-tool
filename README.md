# HL + PD Calculator

Heat Load (THL) and Pressure Drop (PD) calculator for HVAC design work by Vic Air.

Web app: sign in, admin approves your account, then use the calculator.

## Features

- Multi-session THL and PD tabs (unlimited).
- Auto Take-Off: upload a floor plan (JPG / PNG / PDF), set scale + North, draw walls / windows / doors / rooms, apply straight into a THL sub-page.
- Sub-pages with a live Σ Total tab; merge / un-merge sub-pages via Ctrl+drop or right-click.
- Room properties (name, colour, opacity, ventilation + kW rule-of-thumb overlays, sticky notes).
- WYSIWYG PDF export of any view.

## Access

Log in with your username + password on the login screen. New accounts require
Admin approval before the calculator becomes available.
